# AI Vision Platform - Frontend

基于 Vue 3 + TypeScript + Vite 的 AI 视觉平台前端。

## 技术栈

- **框架**: Vue 3 (Composition API)
- **语言**: TypeScript
- **构建**: Vite
- **状态管理**: Pinia
- **路由**: Vue Router
- **UI**: 自定义组件
- **视频播放**: flv.js (HTTP-FLV)
- **实时通信**: WebSocket

## 快速开始

### 1. 安装依赖

```bash
pnpm install
# 或
npm install
```

### 2. 启动开发服务器

```bash
pnpm dev
# 或
npm run dev
```

### 3. 构建生产版本

```bash
pnpm build
# 或
npm run build
```

## 主要功能模块

### 仪表盘
- 系统概览、统计图表
- 今日告警统计、设备在线状态
- 告警趋势图表

### 视频预览
- 实时视频流查看 (flv.js 播放 HTTP-FLV)
- AI 检测框叠加显示 (Canvas 层)
- 多画面分屏布局
- 通过 WebSocket 接收实时检测结果

### 摄像头管理
- 摄像头 CRUD、RTSP 连接测试
- 区域树形管理
- 摄像头算法配置（选择启用的检测能力）
- 检测区域绘制

### 模型管理
- 模型上传与管理
- 查看模型支持的检测类别
- 查看关联的检测能力列表

### 算法管理（检测能力）
- 检测能力配置
- 关联模型、指定检测类别
- 配置默认置信度阈值
- 配置告警条件（立即/持续/计数）

### 告警管理
- 告警列表、筛选、处理
- 告警详情（截图、视频片段）
- 实时告警推送 (WebSocket)

### 推送管理
- 告警推送渠道配置
- 邮件、钉钉、微信等

### 系统管理
- 用户、角色、权限管理
- 操作日志
- 系统设置

## 视频播放与检测框叠加

### 技术方案

```
┌─────────────────────────────────────────────────────────────┐
│  视频播放组件                                                │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  ┌───────────────────────────────────────────────────────┐ │
│  │                                                       │ │
│  │   <video> 层：flv.js 播放 HTTP-FLV 流                  │ │
│  │                                                       │ │
│  │   ┌───────────────────────────────────────────────┐  │ │
│  │   │                                               │  │ │
│  │   │  <canvas> 层：绘制 AI 检测框                   │  │ │
│  │   │  - 根据 WebSocket 推送的检测结果绘制           │  │ │
│  │   │  - 不同算法用不同颜色                          │  │ │
│  │   │  - 显示标签和置信度                            │  │ │
│  │   │                                               │  │ │
│  │   └───────────────────────────────────────────────┘  │ │
│  │                                                       │ │
│  └───────────────────────────────────────────────────────┘ │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

### WebSocket 数据格式

```typescript
// 检测框数据 (用于 Canvas 绘制)
interface DetectionMessage {
    type: "detections";
    camera_id: string;
    frame_id: number;
    timestamp: number;
    detections: Array<{
        algo: string;       // 算法标识
        label: string;      // 检测标签
        bbox: [number, number, number, number];  // [x, y, width, height]
        conf: number;       // 置信度
    }>;
}

// 告警数据 (用于告警列表)
interface AlarmMessage {
    type: "alarm";
    camera_id: string;
    alarm: {
        id: number;
        level: "info" | "warning" | "danger";
        title: string;
        algorithm: string;
        image_url: string;
        created_at: string;
    };
}
```
